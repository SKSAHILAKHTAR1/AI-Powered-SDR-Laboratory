# AI-Powered-SDR-Laboratory
Real-time AI SDR simulator in Python. Models AM, DSB-SC &amp; SSB-SC (Hilbert transform) pipelines inside a PyQt5/pyqtgraph cyberpunk GUI. Features AWGN/multipath fading, interactive mouse waveform drawing, FFT/Waterfall plots, live audio, and RF signal classification via an embedded Random Forest.
